# Mobile branding

A identidade instalada do **Motor de Inteligência Esportiva** usa ícones próprios em `public/icons/`:

- `favicon-32.png`
- `apple-touch-icon.png` (180x180)
- `icon-192.png`
- `icon-512.png`

No iOS, o ícone da Tela de Início pode ficar em cache. Depois de uma troca de ícone, remova o atalho antigo e adicione o site novamente pelo Safari para forçar a nova arte.

A experiência mobile preserva a mesma navegação e identidade do produto web, com prioridade para safe-area, alvos de toque de pelo menos 44 px e bottom navigation nas cinco superfícies principais.

A sessão mobile usa Google e Lovable Cloud normalmente e mantém um marcador local apenas para exigir nova autenticação após 30 dias. Esse marcador não substitui autenticação, allowlist ou validação das server functions.
